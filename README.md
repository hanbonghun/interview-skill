## 소개

`/interview` 스킬은 Claude Code 안에서 동작하는 AI 기술 면접관입니다.

**주요 기능:**

- 이력서와 채용공고(JD)를 바탕으로 맞춤형 기술 질문 생성
- 실제 면접처럼 자유로운 대화 형식으로 진행
- 답변이 부족하면 꼬리 질문으로 심화
- 면접 종료 시 3가지 리포트 자동 생성:
  1. **Q&A 전체 기록** — 내 답변 + 모범 답안
  2. **보완할 점 & 미흡한 CS 포인트** — 학습 방향 포함
  3. **종합 평가** — 강점, 약점, 총평
- 리포트를 `.md` 파일로 로컬 저장

## 설치

### 1. 저장소 클론

**SSH (권장):**
```bash
git clone git@github.com:hanbonghun/interview-skill.git
```

**HTTPS:**
```bash
git clone https://github.com/hanbonghun/interview-skill.git
```

### 2. 스킬 경로 등록

`~/.claude/settings.json` 파일을 열어 `skills.paths` 에 클론한 디렉토리 안의 `skills` 폴더 경로를 추가합니다.

**파일이 없는 경우** — 새로 생성합니다:
```json
{
  "skills": {
    "paths": ["/Users/yourname/interview-skill/skills"]
  }
}
```

**이미 `settings.json` 이 있는 경우** — `skills.paths` 배열에 경로를 추가합니다:
```json
{
  "skills": {
    "paths": [
      "/Users/yourname/other-skill/skills",
      "/Users/yourname/interview-skill/skills"
    ]
  }
}
```

> `/Users/yourname/interview-skill` 부분을 실제 클론한 경로로 변경하세요.
> 확인 방법: 클론한 디렉토리 안에서 `pwd` 실행

### 3. Claude Code 재시작

설정 파일 변경 후 Claude Code를 재시작해야 스킬이 인식됩니다.

### 4. 설치 확인

Claude Code에서 아래를 입력해 스킬이 나타나는지 확인합니다:
```
/interview
```

## 사용법

### 방법 1: 파일 경로로 시작

이력서와 JD 파일 경로를 직접 전달합니다.

```
/interview resume.pdf jd.txt
```

```
/interview ~/Documents/resume.md ~/Downloads/wanted-jd.pdf
```

- 지원 형식: `.pdf`, `.txt`, `.md`, `.docx` 등 Claude Code가 읽을 수 있는 모든 형식
- 파일은 순서 무관 — Claude가 이력서와 JD를 내용으로 구분합니다

### 방법 2: 텍스트 붙여넣기로 시작

파일 없이 내용을 직접 붙여넣을 수도 있습니다.

```
/interview
```

실행 후 안내에 따라 진행합니다:

```
이력서 내용을 아래에 붙여넣어 주세요.

▶ (이력서 내용 붙여넣기)

감사합니다. 이번엔 지원하시는 회사의 채용공고(JD)를 붙여넣어 주세요.
JD가 없으면 '없음'을 입력하세요.

▶ (JD 내용 붙여넣기 또는 '없음' 입력)

확인했습니다. 면접을 시작하겠습니다.
```

### 방법 3: 혼합

파일과 붙여넣기를 함께 사용할 수 있습니다. 예를 들어 이력서 파일만 제공하면 JD는 붙여넣기로 안내합니다.

```
/interview resume.pdf
```

### 면접 진행

면접이 시작되면 Claude가 이력서와 JD를 분석해 맞춤형 질문을 제시합니다.

```
네, 이력서를 보니 Spring Boot와 JPA를 주로 사용하셨군요.
첫 번째 질문입니다.

JPA에서 N+1 문제가 무엇인지, 그리고 어떻게 해결하셨는지 설명해 주시겠어요?
```

답변하면 피드백과 다음 질문이 이어집니다. 자유롭게 대화하듯 답변하면 됩니다.

---

### 면접 종료 및 리포트 생성

면접을 끝내고 싶을 때 아래를 입력합니다:

```
done
```

Claude가 리포트를 생성하고 현재 디렉토리에 파일로 저장합니다.

```
수고하셨습니다. 면접 결과를 정리하겠습니다.

...

리포트가 interview-report-2026-04-14-15-30.md 로 저장되었습니다.
```

> 리포트 파일명: `interview-report-YYYY-MM-DD-HH-MM.md`
> 저장 위치: `done` 을 입력한 시점의 현재 작업 디렉토리

```markdown
# 기술 면접 리포트

**날짜:** 2026-04-14 15:30
**지원 포지션:** 백엔드 개발자 (Java/Spring)

---

## 1. Q&A 전체 기록

### Q1. JPA에서 N+1 문제가 무엇인지, 어떻게 해결하셨는지 설명해 주시겠어요?

**내 답변:**
연관 엔티티를 조회할 때 쿼리가 N번 추가로 나가는 문제입니다.
Fetch Join이나 @EntityGraph로 해결했습니다.

**모범 답안:**
N+1 문제는 ORM이 연관 관계를 지연 로딩(Lazy Loading)할 때 발생합니다.
부모 엔티티 1건을 조회한 후, 연관된 자식 엔티티를 각각 개별 쿼리로 조회하면서
총 N+1번의 쿼리가 실행됩니다.

해결 방법:
1. **Fetch Join**: `SELECT o FROM Order o JOIN FETCH o.items` — 한 번의 쿼리로 연관 데이터를 함께 조회
2. **@EntityGraph**: 어노테이션으로 선언적으로 Eager 로딩 지정
3. **Batch Size 설정**: `@BatchSize(size=100)` 으로 IN 쿼리로 일괄 조회
4. **QueryDSL + DTO 프로젝션**: 필요한 필드만 선택해 조회

주의: Fetch Join + 페이지네이션 동시 사용 시 메모리에서 페이징 처리가 발생하므로 주의가 필요합니다.

## 2. 보완할 점 & 미흡한 CS 포인트

- **JPA 페이지네이션 + Fetch Join 충돌**: 실무에서 자주 마주치는 이슈입니다. `countQuery`를 분리하거나 DTO 프로젝션으로 우회하는 방법을 익혀두세요.
- **트랜잭션 격리 수준**: 답변에서 언급되지 않았습니다. REPEATABLE READ vs READ COMMITTED 차이와 각 격리 수준에서 발생하는 현상(Dirty Read, Phantom Read 등)을 정리해두세요.

## 3. 종합 평가

**강점:**
- 실무 경험에서 나온 구체적인 답변이 인상적이었습니다.
- 기술적 개념을 명확하게 설명하는 능력이 좋았습니다.

**약점:**
- CS 이론 기반 질문에서 다소 추상적인 답변이 나왔습니다.
- 트레이드오프를 언급하는 부분에서 아쉬움이 있었습니다.

**총평:**
실무 경험을 바탕으로 한 답변 능력은 우수합니다. CS 기초와 설계 관점에서의 트레이드오프 설명을 보완하면 더 높은 평가를 받을 수 있을 것입니다.
```

## 팁

**면접 전 준비:**
- 지원할 JD를 저장해두고 파일 경로로 바로 불러오면 편합니다.
- 이력서는 최신 버전으로 준비하세요. Claude가 이력서를 기반으로 질문을 생성합니다.

**면접 중:**
- 짧은 답변보다 실제 프로젝트 경험을 연결해서 답변하면 더 심도 있는 피드백을 받을 수 있습니다.
- 모르는 내용은 솔직하게 "잘 모르겠습니다"라고 답변해도 됩니다. 어떤 부분이 부족한지 리포트에 반영됩니다.
- 답변 후 꼬리 질문이 오면 실전처럼 대응해보세요.

**리포트 활용:**
- 모범 답안과 내 답변을 비교해 부족한 개념을 확인하세요.
- "보완할 점" 섹션을 스터디 플랜으로 활용하면 효과적입니다.
- 면접을 여러 번 반복하면 날짜/시각이 포함된 파일명 덕분에 이력이 남습니다.

## FAQ

**Q. JD 없이도 면접이 가능한가요?**
네. JD 입력 안내 시 `없음` 을 입력하면 이력서만으로 면접을 진행합니다.

**Q. 면접 도중 다시 시작할 수 있나요?**
Claude Code 대화를 새로 시작하고 `/interview` 를 다시 실행하면 됩니다.

**Q. 리포트 파일이 어디에 저장되나요?**
`done` 을 입력한 시점의 현재 작업 디렉토리에 저장됩니다. 특정 디렉토리에 저장하려면 해당 디렉토리로 이동한 후 면접을 시작하세요.

**Q. 영어 이력서/JD도 되나요?**
네. Claude가 이력서와 JD 언어를 자동으로 인식합니다. 단, 면접 진행과 리포트는 한국어로 출력됩니다.

**Q. 설치 후 `/interview` 명령어가 인식되지 않아요.**
- `~/.claude/settings.json` 경로가 정확한지 확인하세요.
- `skills/` 폴더 경로가 올바른지 확인하세요 (interview-skill 저장소 루트가 아닌 `skills/` 하위 폴더여야 합니다).
- Claude Code를 완전히 종료 후 재시작해보세요.

## 삭제

1. `~/.claude/settings.json` 에서 등록한 경로를 제거합니다.
2. 클론한 `interview-skill` 디렉토리를 삭제합니다.

```bash
rm -rf /path/to/interview-skill
```
